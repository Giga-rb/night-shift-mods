# Как добавить свой мод

1. Выложите мод в публичный репозиторий на GitHub и создайте **Release** с zip-файлом (кнопка «Скачать» берёт файл оттуда).
2. Откройте страницу **«Предложить мод»** на сайте, заполните форму, при желании приложите картинку (PNG/JPG до 700 КБ) и отметьте нужные моды-зависимости. Входить не нужно.
3. Модератор проверит заявку, и мод появится в каталоге.

Через Pull Request тоже можно: добавьте `mods/ваш-ник-название.json` (поля: name, author, description, repo, image, dependencies, tags).
